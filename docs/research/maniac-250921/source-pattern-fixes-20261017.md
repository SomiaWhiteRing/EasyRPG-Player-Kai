# SELF、状态参数与逃跑消费链修复

基线 4e87bb860，版本 2026.10.5。本轮修复前次 REA 对照确定的五项问题，没有扩大为全面 Maniac 兼容声明。

- GetActors 的变量角色选择使用解释器 ReadVariable，支持当前执行帧 SELF，普通模式继续读取全局变量。
- 10480 状态指令读取第5参数低四位的状态模式（0常量、1变量、其余间接），并只在该指令接入原版的间接角色选择；没有给其他角色指令机械增加相同选择模式。状态值在每个目标效果前读取，保留状态钩子改变变量后影响后续目标的顺序。
- 11520 BGM淡出按第2参数低四位读取时长，复用音频接口。
- 1006 强制逃跑在Maniac下同时写入战斗级请求，场景更新和逃跑判定均消费该请求，避免独立公共事件／目标钩子仅写局部标志而丢失效果。Init/Quit均清空请求；原有普通模式保留。
- Maniac的我方／全体敌方逃跑选项低位0绕过阵形检查、低位1执行检查；指定敌人始终受包围阵形限制。普通2k3旧规则不变。
