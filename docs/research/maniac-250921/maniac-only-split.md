# Maniac 独立分支拆分记录

本分支从拆分前的 `my-feature-stable`（`f28c77ac7`）建立。旧的上游提交 `78328fa29` 用于辨认主分支相对上游增加的功能，不以新版上游替换基线。

任务是从这份已有差异中单独拆出 Maniac 兼容：保留原有的 Maniac 实现，撤去其他追加功能，并修复拆分导致的依赖或宿主断接。原主分支已有的 Maniac 缺口、缺陷和未实现模式不属于本任务的新开发目标；不以原版 RPG_RT 的行为重新补写一套兼容。

## 已拆除的功能

拼音、交互高亮、小字、消息历史、视频播放、附带 SoundFont、站点导入器和归档站 Web 宿主等独立功能已从此分支移除。本次继续移除了独立的 `--detect-encoding` 命令和等待期间预解码大图片的优化；Maniac 游戏仍由普通图片加载路径同步读取图片。非 Maniac 游戏恢复原本的队员 ID 为零提示和事件位置模式处理，Maniac 游戏保留原来的相应兼容行为。

## 图片共享代码的取舍

- `Cache::LoadBitmap` 对 Maniac 的图片和图块设置 `Flag_ManiacPicture`；`Bitmap` 在颜色预乘之前保存原始 RGBA，供 Maniac 图片渲染、像素读取和透明度相关操作使用。普通 PNG 加载器保留零透明度像素的 RGB，因此不依赖已删除的预加载器。
- `Bitmap::WritePNG` 的透明通道输出被 Maniac 的图片写出命令使用，予以保留。
- 大图片的分块复制和精灵帧视图是共享绘图基础设施：用于避开 Pixman 的大尺寸坐标限制，让使用超大素材的游戏仍能显示。它们并非提前加载优化，予以保留。

## 三端衔接和检查范围

- Windows：Maniac 的系统音量接口使用 `winmm`，CMake 现无论原生 MIDI 是否启用都链接该库。
- Android：使用当前 SDL3 的 `SDL.setContext(Activity)` 接口；本机 SDL3 3.4.8 AAR 的声明已作静态核对。触摸输入、普通字体和 Android 宿主仍由 EasyRPG 处理。
- Web：使用标准 EasyRPG SDL 宿主，并保留 Maniac 控制台、输入和存档接入。旧归档站的浏览器存档位于不同路径，不会自动迁入；需通过存档导出、导入处理已有的游戏存档。
- 三端共用的 `liblcf` 必须包含 Maniac 存档字段。默认从已兼容的本地源码构建；本地源码缺少这些接口时，在构建目录获取固定版本并应用仓库中的补丁。现有本地工作副本及其修改不受影响。补丁已在临时干净源码上静态应用并核对所需接口。

## 2026-10-27 范围纠偏

后两轮验收把已有 Maniac 的行为补完混入了拆分，超出了本任务范围。本次在保留提交历史的前提下撤回这些新增实现：

|来源|撤回内容|
|---|---|
|`1eb224ef4`|扩展按键新增 SELF 目标、零目标处理，以及按键和鼠标结果改用原始变量写入|
|`0cce820e6`|存档信息、图片几何、媒体选项及地图/战斗/钩子保存结果改用原始变量写入|
|`0cce820e6`|Web 通用触控取消和越界滑动修复、SDL3 原生触摸取消处理、通用错误报告增强|
|`0cce820e6`|可选 Windows SDL3 后端的窗口句柄接口和额外 `dwmapi` 链接修复；原有 Windows SDL2 路径继续保留|

继续保留的后续改动仅用于让拆分后的宿主能够运行：

- Web 使用当前工具链已有的 SDL3 图形和音频后端。
- 将游戏工作目录和默认 IDBFS 选择移到 `preRun`，确保挂载存档前已经完成初始化。
- 删除读取 `/tmp/message.png` 的失效退出回调；拆分后的 Player 已没有该文件的生产者。

上一轮把 `Invalid write` 调试日志解释为写入失败也不准确：普通 `Game_Variables::Set` 仍会扩展变量，但执行数值裁剪。本次恢复主分支原有写回规则，不在拆分任务中修正它。手柄等原有未实现分支同样不作为后续自动补完项。

`e4c549e1e` 纠偏时仅完成静态检查；更早的三端产物包含已撤回的兼容增强，不作为纠偏后版本的交付。以下重新构建和验收针对本轮源码，未新增永久测试代码。

### 重新构建和运行

- Windows：沿用原有 SDL2 配置，Release Player 与现有测试运行器重新构建成功。91 个 Maniac 用例在独立进程中分别通过，共 1924 项断言；共享字体/文本/解析的 28 个用例按 26 个名称筛选通过，共 370 项断言。无界面运行验证 2048×2048 图集原始像素及保存/恢复；另确认原分支的数值裁剪仍保留，没有带回前两轮新增的写回语义。系统已有视频设置未变。
- Web：SDL3 构建成功。Chrome 中确认中文控制台输入、普通存档与 `Save.lgs` 刷新恢复、原始透明像素，以及窗口 2 倍缩放、实际居中位置、插值切换、缩放后的按键按下/松开和鼠标坐标。显示选项的任务内旧/新代码对照经过 11 个步骤，结果一致。保存并退出无脚本异常。全屏入口出现、返回窗口模式正常；当前浏览器拒绝全屏请求（`not granted`），实际进入浏览器全屏未记为通过，没有改变浏览器约束或新增替代实现。
- Android：重新构建 ARM64 调试包，使用独立包名 `org.easyrpg.player.kai.codexmaniac`，在独立 Android 12 模拟器的 ARM64 兼容层中安装运行。控制台输入、全局及普通存档在应用重启后恢复，图片像素一致；虚拟按钮、键盘确认及原有窗口/全屏视口切换通过。未覆盖实体 Android 设备。

Windows 与 Android/Web 构建实际使用的五个 `liblcf` 存档结构和读取实现文件也已直接核对一致。本轮独立产物和检查记录位于 `build/maniac-split-final-20261027/artifacts/` 与 `evidence/`。这些有限运行检查验证拆分保留和宿主连接，不表示修正了原分支的全部 Maniac 缺口。原有手柄等未实现分支保持原状。
