# Maniac 独立分支拆分记录

本分支从拆分前的 `my-feature-stable`（`f28c77ac7`）建立。旧的上游提交 `78328fa29` 只用于辨认后来追加的行为，不是本次分支的基线。

## 已拆除的功能

拼音、交互高亮、小字、消息历史、视频播放、附带 SoundFont、站点导入器和归档站 Web 宿主等独立功能已从此分支移除。本次继续移除了独立的 `--detect-encoding` 命令和等待期间预解码大图片的优化；Maniac 游戏仍由普通图片加载路径同步读取图片。非 Maniac 游戏恢复原本的队员 ID 为零提示和事件位置模式处理，Maniac 游戏保留原来的相应兼容行为。

## 图片共享代码的取舍

- `Cache::LoadBitmap` 对 Maniac 的图片和图块设置 `Flag_ManiacPicture`；`Bitmap` 在颜色预乘之前保存原始 RGBA，供 Maniac 图片渲染、像素读取和透明度相关操作使用。普通 PNG 加载器保留零透明度像素的 RGB，因此不依赖已删除的预加载器。
- `Bitmap::WritePNG` 的透明通道输出被 Maniac 的图片写出命令使用，予以保留。
- 大图片的分块复制和精灵帧视图是共享绘图基础设施：用于避开 Pixman 的大尺寸坐标限制，让使用超大素材的游戏仍能显示。它们并非提前加载优化，予以保留。

## 三端衔接和检查范围

- Windows：Maniac 的系统音量接口使用 `winmm`，CMake 现无论原生 MIDI 是否启用都链接该库。
- Android：使用当前 SDL3 的 `SDL.setContext(Activity)` 接口；本机 SDL3 3.4.8 AAR 的声明已作静态核对。触摸输入、普通字体和 Android 宿主仍由 EasyRPG 处理。
- Web：使用标准 EasyRPG SDL 宿主，并保留 Maniac 控制台、输入和存档接入。旧归档站的浏览器存档位于不同路径，不会自动迁入；需通过存档导出、导入处理已有的游戏存档。
- 三端共用的 `liblcf` 必须包含 Maniac 存档字段。默认从已兼容的本地源码构建；本地源码缺少这些接口时，在构建目录获取固定版本并应用仓库中的补丁。现有本地工作副本及其修改不受影响。补丁已在临时干净源码上静态应用并核对所需接口。

本记录覆盖源码拆分和静态核对。尚未构建或运行三端程序，也未在真实游戏、设备或浏览器中验收，不能据此认定全部 Maniac 行为及三端运行时兼容已完成。
